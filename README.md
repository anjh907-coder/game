# 🎨 픽셀 & 코딩 스튜디오 (Pixel & Coding Studio)
> **초등학교 3~4학년 소프트웨어(SW) 및 인공지능 기초 교육 웹 플랫폼**
> 1. 나만의 픽셀아트 게임 캐릭터 만들기 & 스크래치(Scratch) 스프라이트 다운로드
> 2. 직접 그린 캐릭터로 모험을 떠나는 Code.org 스타일 10단계 블록 코딩 챌린지

---

## 🌟 2가지 메인 탭(Tab) 구성

### 탭 1: 🎨 픽셀아트 캐릭터 그리기
- **초등 3~4학년 맞춤형 픽셀아트 교육 팝업 ("픽셀아트란 뭘까?")**:
  - 점이 모여 그림이 되는 디지털 원리 (돋보기 vs 멀리서 보기)
  - 마인크래프트와 고전 게임 비유
  - 스크래치에서 꼭 필요한 **투명 배경**의 비밀
- **캔버스 도구**:
  - 8x8 (초급), 16x16 (추천), 24x24 (심화)
  - 연필(클릭/드래그), 지우개, 페인트통(Flood Fill), 스포이드
  - **좌우 대칭 모드(Symmetry)**: 얼굴/몬스터 그릴 때 반대쪽 자동 완성
  - 모눈 격자선 토글, 25단계 되돌리기(Undo)/다시실행(Redo)
- **스크래치 최적화 다운로드**:
  - 완전 투명 배경 PNG
  - **Nearest-Neighbor 업스케일링**: 16x16 원본, **256x256 (스크래치 추천)**, 512x512 고화질 선명 저장
  - 스크래치 무대 실시간 시뮬레이터 (통통 튀는 애니메이션 및 무대 배경 선택)
  - 스크래치 1분 연계 가이드 수록

### 탭 2: 🚀 블록 코딩 모험 (10단계 챌린지)
스크래치 블록 조립 방식과 100% 호환되는 드래그 앤 드롭/클릭 조립 블록 코딩 플랫폼입니다.
- **화면 구성**: `[왼쪽: 격자 맵 및 캐릭터/목표물] | [가운데: 블록 보관함] | [오른쪽: 내 작업 공간 & 실행/리셋]`
- **캐릭터 자동 연동**: **탭 1에서 아이가 직접 그린 픽셀 캐릭터가 맵 위를 직접 걷고 회전하는 주인공으로 자동 반영**됩니다.
- **스크래치 규격 블록**:
  - `[앞으로 한 칸 걷기]` (파란색 동작 블록)
  - `[오른쪽으로 돌기 ↻]` / `[왼쪽으로 돌기 ↺]`
  - `[아이템 줍기 💎]` (초록색 수집 블록)
  - `[__번 반복하기]` (주황색 제어 블록, 중첩 지원)
  - `[만약 여기에 아이템이 있으면]` / `[만약 앞에 장애물이 있으면]` (조건문 블록)
- **8단계 단계별 커리큘럼**:
  - **Level 1 (방향 회전 감각):** 앞으로 가다가 우회전하여 보물 상자 도착.
  - **Level 2 (연속 회전 & 지그재그):** 좌회전과 우회전을 번갈아 하며 징검다리 건너기.
  - **Level 3 (반복문 입문):** 5칸 떨어진 목표물까지 `[앞으로 걷기]` 블록을 일일이 쓰지 않고 `[5번 반복]`으로 해결.
  - **Level 4 (계단 오르기 반복):** (앞으로 가기 + 위로 돌기) 패턴을 `[3번 반복]`으로 최적화.
  - **Level 5 (장애물 우회):** 정면에 벽(돌/용암)이 있어 옆으로 돌아서 지나가기.
  - **Level 6 (사각 순환 코스):** 반복문을 활용해 사각형 둘레를 돌아 깃발 획득.
  - **Level 7 (조건문 & 아이템 수집):** 반복문 안에 `[만약 여기에 아이템이 있으면 ➡️ 아이템 줍기]`를 넣어 길목의 보석을 모두 챙겨 보물 상자 도착.
  - **Level 8 (최종 보스 미션 - 5x5 완주 & 제자리 귀환):** 5x5 사각형 둘레를 돌며 반복문 안에 조건문(`아이템 줍기`, `장애물 앞 우회전`)을 조합하여 모든 보석을 먹고 제자리(출발점)로 돌아와 최종 엔딩 클리어!
- **피드백 시스템**:
  - 0.38초 간격 부드러운 이동/회전 애니메이션 및 실행 중인 블록 실시간 하이라이트
  - 한 걸음씩 실행(Step) 디버깅 모드
  - 성공 시 3스타 평가 축하 모달 & 실패 시 구체적인 방향 힌트 말풍선
  - Web Audio API 8비트 사운드 효과음 (걸음음, 회전음, 보석 획득 챠링, 쿵 부딪힘, 성공 팡파르)

## 🚀 GitHub & Vercel 배포 방법

이 프로젝트는 Vite 기반 React SPA로 정적 파일(`dist`)로 빌드되어 Vercel에 단 1분 만에 배포할 수 있습니다.

1. 프로젝트 파일을 GitHub에 푸시(Push)합니다.
2. [Vercel](https://vercel.com)에서 **Add New... > Project**를 누르고 레포지토리를 연결(Import)합니다.
3. 사전 설정된 `vercel.json`에 의해 추가 설정 없이 바로 배포 완료!
